# Save a compiled table script to an R file

Compiles the spec with
[`kst_compile`](https://crow16384.github.io/ksTable/reference/kst_compile.md)
and writes the resulting R script to a file with an informational header
comment block. The saved file is a self-contained plain R script that
can be read, reviewed, version- controlled, or sourced directly.

## Usage

``` r
kst_save(json_spec, file, overwrite = FALSE)
```

## Arguments

- json_spec:

  JSON string or path to a `.json` file.

- file:

  Output path (typically a `.R` file).

- overwrite:

  Logical. If `FALSE` (default), stops when `file` already exists,
  protecting manually-edited scripts.

## Value

The normalised absolute path to the written file, invisibly.

## Details

To execute the saved script:


    env      <- new.env(parent = environment())
    env$data <- my_data
    result   <- source("my_table.R", local = env)$value

## See also

[`kst_compile`](https://crow16384.github.io/ksTable/reference/kst_compile.md),
[`kst_validate_spec`](https://crow16384.github.io/ksTable/reference/kst_validate_spec.md)

## Examples

``` r
spec <- '{
  "schema_version": "1.0",
  "table_spec": {
    "id": "demo",
    "parameter":  { "age": { "variable": "AGE" } },
    "statistics": { "n": { "fun": "length" } },
    "groups":     { "by": ["TRT"] },
    "layout":     { "row_structure": "parameter_stat" }
  }
}'
tmp <- tempfile(fileext = ".R")
kst_save(spec, tmp)
cat(readLines(tmp), sep = "\n")
```
